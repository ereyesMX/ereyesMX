# profile/

Estructura inicial creada para alojar tu perfil y recursos para GitHub Pages.

Arbol principal:

profile/
├─ src/
│  ├─ index.html
│  ├─ about.html
│  ├─ css/
│  │  └─ main.css
│  ├─ js/
│  │  └─ main.js
│  └─ assets/
│     ├─ images/
│     ├─ icons/
│     └─ favicons/
├─ manifest.json

Qué sigue:
- Sube tus imágenes reales a profile/src/assets/images y los favicons a profile/src/assets/favicons
- Cuando quieras publicar en GitHub Pages, copia el contenido de profile/src a /docs o configura una acción para desplegar a gh-pages.
